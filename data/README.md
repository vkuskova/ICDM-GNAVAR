# Data dictionary

This directory documents the datasets used. Raw third-party data are **not**
redistributed here; each is publicly available from its original source (cited
below and in the paper). The synthetic generator is in `src/gnavar_core.py`.

## Synthetic (Sections VI-A, VI-B)
Generated by `simulate_dgp` / `simulate_dgp_coupled` in `src/gnavar_core.py`.
Ground-truth structure: source x2 modulated by x3, source x4 by x5 (two true
two-way interactions). Fully reproducible from seed; no external file.

## Beijing Multi-Site Air Quality (Section VII)
Hourly readings of pollutants and meteorology at monitoring stations, 2013-2017.
Source: Zhang et al., "Cautionary tales on air-quality improvement in Beijing",
Proc. R. Soc. A 473(2205):20170457, 2017. Public via UCI Machine Learning
Repository. We use four sites (Nongzhanguan, Tiantan, Huairou, Gucheng).
- `results/experiment_beijing/results.csv` columns: site, setup, target, n_train,
  n_test, r_eff, mse_{train,test}_{gnavar,pairwise}, mse_ratio_pw_to_gn,
  expected_edge_triv_score, modulator_dict_json, triv_scores_json.
- `triv_score_rankings.csv`: per (site,setup), the expected modulator's rank and
  the full candidate ranking by gate triviality score.

## Realized volatility (Section VII)
Daily realized volatility for international equity indices, ~2,615 trading days.
Source: Son et al., "Forecasting global stock market volatility...", J. Forecast.
42(7):1539-1559, 2023.
- `results/experiment_rv/results.csv` columns: target, r_eff, seed_agreement,
  most_common_top_modulator, mean_top_margin, spx_rank1_count, n_peer_edges,
  mse_ratio_pw_to_gn, edges_seed0_json.

## WDI development indicators (Section VII)
World Development Indicators country-year panel, 1970-2023.
Source: World Bank, World Development Indicators, 2024.
- `results/experiment_wdi_resource_curse/results.csv` columns: edge, target,
  r_eff, predicted_modulator, top_seed0, top_seed1, seed_agree, mse_gnavar,
  mse_additive, ranking_seed{0,1}, slopes_seed{0,1}.
- Edge: resource_rents -> gdp_growth, candidate modulators {investment,
  trade_openness, fdi}. Target and sources winsorized at train 1st/99th pct.
